# Iterator Pet · 雨世界迭代器桌宠

一只《雨世界》（Rain World）迭代器桌宠，内置**五块卵石和仰望皓月**，并支持**自定义属于你自己的迭代器**（外观、配色、像素画部件、台词、角色卡、独立世界书）。

我完全不做测试！如果你遇到了 BUG，请向我反馈，否则我大概率永远不会发现。

\---

## 发布版快速上手

发布包解压后，直接双击 **`启动.exe`**。

### 首次运行 / 之后每次

* **第一次运行**：自动在 Steam 库里寻找正版 Rain World；找不到时会弹窗让你手动选择游戏根目录（里面有 `RainWorld.exe` 和 `RainWorld\_Data` 文件夹）。提取出的基础图元会缓存在桌宠目录的 `cache/` 下。
* **之后每次运行**：配置里的路径还在就直接启动；缓存缺了才会重新切一次。
* **重新指定游戏目录**：运行 `启动.exe --setup`。

### 怎么退出

1. 右键**托盘图标** → `退出`（Windows 11 默认把新图标折进任务栏右下角的 `^` 里，看不见就点一下 `^`）。
2. **右键人偶本身** → `退出`（开启「鼠标穿透」时不可用）。
3. 任何时候按快捷键 **`Ctrl+Alt+Q`** 强制退出。

## 功能一览

### 1\. 日常行为与互动

1. **漫游与注视**：迭代器会在你的屏幕上无所事事地漫游，因为这里没有三重肯定可以算。鼠标移动时有概率跟过来观察（`investigate`）；鼠标悬停静止时，随时间增加触发凑近搭话（`talk`）的概率。
2. **戳一戳与拖拽**：

   * **点一下（戳人偶）**：左键轻点人偶会触发「戳一下」反应台词；如果迭代器正在打坐或休眠，会被你戳醒。
   * **拖拽**：按住左键拖动可以拎起人偶本体，或沿着轨道拖动滑车底座。迭代器会对拖拽作出不同反应，不过通常都不是什么好反应。
   * **心情与仪式**：连续粗暴拖拽会降低心情。五块卵石被惹毛后会启动仪式**企图杀掉你的鼠标指针**；仰望皓月则会挣脱开。
3. **打坐与空闲自语**：

   * 光标静止满 30 分钟后，漫游中的迭代器有概率就地**闭眼打坐**。
   * 连续 20 分钟没有任何互动时，会触发一次**空闲自语**。
   * 每次启动完成预热后，会触发一次**启动问候**。
4. **托盘状态指示**：右键托盘菜单首行与图标悬停提示会实时显示她当前在干什么（`漫游中` / `看着你` / `凑近光标` / `打坐中` / `休眠中` / `仪式中` / `被你拎着`）。

### 2\. 感知你的电脑状态

桌宠以 1 Hz 轻量读取系统状态，并把你的电脑当作所在的迭代器腔室：

* **CPU 高占用 → 主动收敛算力**：当你的 CPU 持续高负载时，迭代器感知到计算机算力正被占用，会**主动调暗光环亮度、关闭电光**以收敛自身消耗；负载降下来后再平缓恢复。
* **内存占用 → 光环记忆位（可选开关）**：光环上的 100 个细条是迭代器的MemoryBit。在右键或托盘菜单勾选 **「光环记忆位随内存」** 后，光环上浮现的记忆位数量会随当前系统内存占用率变化。
* **低电量提醒**：笔记本未接电源且电量 `≤ 20%` 时，光环会自动变暗并触发一次低电量提醒。
* **深夜与无输入休眠**：

  * 深夜（23:00–06:00）光环与电光更柔和，更容易进入打坐。
  * 连续 20 分钟无键鼠输入（深夜为 5 分钟）会自动进入**原地闭眼休眠**；你一动鼠标、敲键盘或戳一下就会醒来。
* **全屏免打扰**：当前台运行全屏游戏或全屏视频时，自动暂停主动搭话与空闲自语，安静待在桌面上不打扰你。

## 角色工坊（迭代器自定义）

右键人偶或托盘菜单 → **「迭代器自定义…」**，一个窗口包含四个页签，顶部可在任意角色之间切换，点击 **「设为当前角色」** 或在菜单 **「当前角色」** 中勾选即可立即上场：

|页签|能做什么|
|-|-|
|**1. 人偶外观**|6 个部位调色盘（身体 / 眼睛 / 衣袍上缘 / 衣袍下摆 / 光环 / 电光）+ 天线三色 + 头顶纹章（跟随基底 / 无 / 自定义像素画）+ **两块像素画板**（头顶 `24×20`、天线 `22×36` 自动左右镜像）+ 右侧实时特写预览|
|**2. 本地对话**|顶部开关 **「不接入LLM时，启用本地对话」**（勾选立即生效）；按角色与 7 类事件（`拖拽` / `长时间静止` / `仪式` / `启动时` / `戳一下` / `空闲自语` / `低电量`）编辑本地台词池，支持插入「（不触发对话）」哨兵调节沉默概率|
|**3. 角色卡**|编辑 `characters/\*.json` 的 8 个酒馆 V2 兼容字段（名字 / 描述 / 性格 / 场景 / 系统提示词 / 回复约束 / 开场白 / 对话示例）|
|**4. 世界书**|条目增删、关键词、次级逻辑（`AND\_ANY` / `AND\_ALL` / `NOT\_ANY` / `NOT\_ALL`）、常驻、触发概率、`order`、插入位置（含 `@depth`）、扫描深度与 Token 预算；顶部可切换 **「共用全局世界书」** 与 **「该角色独立世界书」**|

### 顶部角色管理按钮

|按钮|做什么|
|-|-|
|**新建…**|起一个 `key`（文件名，限 `a-z 0-9 \_ -`）与显示名，选一套骨骼基底（五块卵石 / 仰望皓月）。基底决定眼睛与躯干比例，以及被惹毛时会不会杀鼠标|
|**复制…**|以当前角色为模板完整复制一份（外观、角色卡、未知扩展字段全部保留）|
|**删除**|删除自定义角色卡（内置两位不可删）；聊天记录与本地台词默认保留，弹窗里会单独询问是否一并清理|
|**设为当前角色**|让桌面上的人偶当场切换为正在编辑的这位|

### 画板

* 画板**左键落笔、右键擦除、按住 Alt 吸色**，可随时切换画板底色以便看清深色或浅色像素。

## 大语言模型（LLM）接入

### 怎么配置

右键人偶或托盘菜单 → **「大语言模型…」**：

1. 勾选 **「启用大语言模型」**。
2. 选择服务与协议（默认预置 DeepSeek，支持任意兼容 **OpenAI `/v1/chat/completions`** 或 **Anthropic `/v1/messages`** 的接口）。
3. 填入 API Key，点击 **「获取模型」** 拉取模型列表（也可直接手填模型名），点击 **「测试连接」** 验证。
4. 按需设置采样参数、历史消息条数、三档事件冷却秒数，以及两个扩展开关：**「允许模型控制人偶行动」** 与 **「允许把拖入的文件名发给模型」**，点保存即可。

### LLM 能控制哪些行动

勾选「允许模型控制人偶行动」后，模型除了用 `speak` 说话，还可以调用 `act` 驱动桌宠做出 **9 种行动**：

|动作名|效果|
|-|-|
|`investigate`|跟随你的鼠标光标移动一段时间|
|`talk`|走到鼠标光标旁边悬停注视|
|`move\_to(x, y)`|移动到桌面腔室的指定位置，到站停留 1 秒后恢复漫游|
|`hold(seconds)`|在原地闭眼打坐、保持静止指定秒数（`3 \~ 120` 秒）|
|`look\_at(x, y)`|待在原地不走，只把视线转向指定坐标 3 秒|
|`sleep` / `wake`|主动进入原地闭眼休眠，或从休眠/打坐中醒来|
|`tremble`|起身、发光、散出电光，表达对你的强烈不满（神秘杀猫小技能）|
|`idle`|回到平时的自由漫游|

### 拖入文件

勾选「允许把拖入的文件名发给模型」后，把文件拖到人偶身上松手：

* `.txt` / `.md` / `.csv` / `.doc` / `.docx` / `.xlsx` 会读取正文内容（上限 10,000 字）发给模型点评。
* 其它格式只发送文件名与大小等元信息，不会上传二进制内容。
* 文件名以 **`即时广播-`** 开头时，后面的文件名会被当作你直接对迭代器说的话。

> \*\*隐私提醒\*\*：开启大语言模型并拖入上述文本/表格文档时，文档正文会发送给你配置的模型服务商，且对话会保存在本地 `chats/<角色>.jsonl` 中。`llm.json` 内含明文 `api\_key`，分享桌宠文件夹前请勿把 `llm.json` 一起打包。

## 数据与文件位置

所有配置与存档都放在**桌宠根目录**：

|路径|说明|
|-|-|
|`config.json`|桌宠设置（尺寸档位、当前角色、穿透、光环记忆位开关、画板底色等）|
|`lines.json`|本地对话台词池（保存或手改后 2 秒内热重载生效）|
|`llm.json`|大语言模型连接、采样与冷却设置（**含明文 `api\_key`**）|
|`worldbook.json`|共用全局世界书|
|`worldbooks/<角色key>.json`|角色独立世界书（存在时优先于全局世界书）|
|`characters/<角色key>.json`|角色卡与自定义人偶外观数据|
|`chats/<角色key>.jsonl`|各角色的滑动对话历史|
|`cache/`|从你本机 Rain World 提取的精灵图元缓存（删掉会自动重切）|
|`launcher.log`|启动与运行日志|

**卸载方式**：直接删除整个桌宠文件夹即可。（若把桌宠放在 `Program Files` 等只读目录，数据会自动退回 `%LOCALAPPDATA%\\IteratorPet\\`。）

## 从源码运行

环境要求：Windows 10/11 + Python 3.12+，本机装有 Rain World。

```powershell
cd IteratorPet
python -m pip install -r requirements.txt   # PySide6 + UnityPy
$env:PYTHONPATH = "src"
python -m iterator\_pet.main                 # 直接启动桌宠（可加 --dev-panel 打开开发者面板）
python -m iterator\_pet.launcher             # 发布版启动器入口（自动探测游戏与切图）
```

如需手动指定 Rain World 安装目录：

```powershell
$env:RAINWORLD\_DIR = "D:\\SteamLibrary\\steamapps\\common\\Rain World"
```
