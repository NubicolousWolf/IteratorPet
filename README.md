# Iterator Pet · 雨世界迭代器桌宠

一只迭代器桌宠，确切地说是fp和lttm桌宠。预计下一个版本加入迭代器完全自定义。

我完全不做测试！如果你遇到了BUG，请向我反馈，否则我大概率永远不会发现。

## 发布版

发布包解开后直接双击启动.exe。

### 怎么退出

三选一，随便哪个：

1. 右键**托盘图标** → 退出。（Windows 11 默认把新图标折进任务栏的 `^` 里，看不见就点一下 `^`）
2. **右键人偶本身** → 退出（开着「鼠标穿透」时这一条不可用）。
3. 按 **Ctrl+Alt+Q**，任何时候都能退出。

### 首次运行 / 之后每次

* **第一次运行**：自动在 Steam 库里找正版 Rain World，找不到会弹窗让你指到游戏根目录（里面有 `RainWorld.exe` 和
`RainWorld\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\_Data` 文件夹）
* **之后每次运行**：配置里的路径还在就直接启动；缓存缺了才重新切一次。



## 从源码运行

```bash
python -m pip install -r requirements.txt   # PySide6 + UnityPy
$env:PYTHONPATH = "src"
python -m iterator\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\_pet.main                 # 桌宠本体
python -m iterator\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\_pet.launcher             # 发布版入口
```

## 功能

1. 迭代器现在会在你的屏幕上无所事事地漫游，因为这里没有三重肯定可以算。
2. 鼠标悬停时，随时间增加触发迭代器看着鼠标的行为的概率，并触发对话。
3. 鼠标移动时，迭代器有概率会追着鼠标跑。
4. 你可以拖拽迭代器的人偶和底座。有很多bug，但你可以。迭代器会对拖拽作出不同反应，不过都不是什么好反应！
5. 托盘菜单 →「角色」可以在内置的五块卵石 / 仰望皓月之间切换，也可以切到你**自己建的迭代器**。
6. 你可以在`lines.json` 里自定义
迭代器们会说的话。也可以直接用菜单编辑对话。
7. 按ctrl+alt+q强制退出。
8. 现在你可以接入LLM，让LLM扮演迭代器和你对话，并阅读你拖到它们脑袋上的文件。详细设置见下。
9. 现在你可以编辑世界书、角色卡，并在角色工坊里给迭代器换配色、在脸上涂涂画画、更换新的天线——**保存后桌面上的人偶当场换装**。
10. 现在你可以新建、复制、删除自己的迭代器了：选一套骨骼基底（五块卵石 / 仰望皓月），剩下的名字、性格、配色、台词都由你定。每个角色还可以有自己的世界书。

### 美术资源

启动时从你自己的 Rain World 安装里提取基础图元，存到**桌宠文件夹**里的 `cache/`。
安装路径可用环境变量覆盖：

```powershell
$env:RAINWORLD\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\_DIR = "D:\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\SteamLibrary\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\steamapps\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\common\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\Rain World"
```

## 大语言模型

1. 右键人偶 →「大语言模型…」：勾「启用大语言模型」→ 选服务（默认 DeepSeek）→ 填 API Key →
点「获取模型」 → 按你的喜好勾选控制行为/阅读文件并设置会发给LLM的历史对话条数 → 保存。
2. （在勾选设置的情况下）LLM可以有限地控制行为。目前来说这只是一个框架，所以迭代器能做的很有限，只是过来看看你，靠近你，以及企图用神秘小技能杀掉你（目前是五块卵石特供！）。而且他们好像不太喜欢做动作。
3. （在勾选设置的情况下）LLM可以阅读你拖到他们脑袋上的文件。.txt .md .csv .doc .docx .xlsx格式文件会阅读内容，其他文件只阅读文件名。可识别的区域会出现“+复制”。迭代器知道他们看的是文件，但以「即时广播-」开头的文件会被认视作直接与迭代器对话。迭代器不会阅读即时广播的内容。文件识别上限是10000字，提示词里有角色输出字数限制和简易反注入，别拿我们迭代器当豆包用。

下面的表格列出了和该功能有关的玩家文件。世界书和角色卡现在都能在工坊里改，直接编辑文件同样有效。世界书和角色卡都是Gemini写的，我大概改了一下，但可能还是有错误和遗漏的地方。

| 文件 | 内容 |
| --- | --- |
| `llm.json` | 连接与采样设置（**含明文 api_key**） |
| `worldbook.json` | 共用的世界书 |
| `worldbooks/<角色>.json` | 某个角色独有的世界书（有它就优先，没有就用上面那份） |
| `characters/*.json` | 角色卡（含外观草稿） |
| `chats/<角色>.jsonl` | 对话历史 |
| `launcher.log` | 启动与拖放日志 |

**隐私提醒**：

* 拖到迭代器身上的 `.txt .md .csv .doc .docx .xlsx`，**正文会被读出来发给模型服务商**，并且**写进 `chats/<角色>.jsonl`长期保存**。

## 角色工坊

右键人偶或托盘菜单 →「**迭代器自定义…**」，一个窗口三个页签：

| 页签 | 能做什么 |
| --- | --- |
| **世界书** | 编辑世界书：条目增删、关键词、次级逻辑、常驻、概率、order、插入位置、正文；最上面可以切「共用全局」与「该角色独立」两种作用域 |
| **角色卡** | 编辑 `characters/*.json` 的 8 个字段（名字/描述/性格/场景/系统提示词/回复约束/开场白/对话示例）；空着的字段有一键兜底 |
| **人偶外观** | 6 个调色盘（身体 / 眼睛 / 衣袍上缘 / 衣袍下摆 / 光环 / 电光）+ 天线三个颜色 + 头顶部件（跟随基底 / 无 / 自定义像素画）+ 两块像素画板（头顶 24×20、天线 12×29，左右镜像）+ 右侧特写预览 |

顶部四个按钮：

| 按钮 | 做什么 |
| --- | --- |
| **新建…** | 起一个 key（文件名，只能是 a-z 0-9 下划线减号）与显示名，选一套骨骼基底。基底决定眼睛高度、躯干高度、以及"她会不会企图杀掉你的鼠标" |
| **复制…** | 以当前角色为底复制一份，外观、卡、未知字段全都带走 |
| **删除** | 只删卡文件；**聊天记录与本地台词默认保留**，想一起删会在弹窗里单独问一次。内置两位删不掉 |
| **设为当前角色** | 让桌面上的人偶换成这一位（等价于在托盘菜单里点她的名字） |

* 画板左键画、右键擦、**按住 Alt 吸色**；有「画板底色」可以换成和部件反差大的颜色。
* 配色与画板会存进角色卡的 `extensions.rainworld.appearance`，**下次打开还在**；保存后如果改的就是桌面上那位，人偶当场换装。
* 世界书作用域：切到「该角色独立」时，如果她还没有自己的那份，会问你要不要把现在的全局世界书复制一份当起点（推荐；之后她和别的角色互不影响）。直接点「复制全局到该角色」也能做同样的事。
* 新建的角色在「自定义对话」里会立刻出现，台词默认是一句「……」，去那里填就行。

## 数据放在哪

全都放在**桌宠文件夹**里（和 `启动.exe` 并排，不往 C 盘写）：

| 文件 | 内容 |
| --- | --- |
| `config.json` | 设置（尺寸、角色、开关、画板底色…） |
| `lines.json` | 迭代器说的话（可以自己加，两秒内生效） |
| `llm.json` | 大模型连接与采样设置（**含明文 api_key**） |
| `worldbook.json` | 世界书 |
| `worldbooks/<角色>.json` | 某个角色独有的世界书（可选；没有就用上面那份） |
| `characters/*.json` | 角色卡（含外观草稿） |
| `chats/<角色>.jsonl` | 对话历史 |
| `launcher.log` | 启动与拖放日志 |
| `cache/` | 从你本机游戏里切出来的图元（删了会自动重切） |

卸载：删掉整个文件夹即可。如果放在只读位置（例如 Program Files），数据会退回 `%LOCALAPPDATA%\IteratorPet\`。

> 别把本文件夹放进带了"低完整性"标记的目录再运行（极少见，一般是某些沙箱/下载工具建的目录）：
> Windows 会拒绝 Low 完整性进程注册托盘图标，表现就是"托盘里没有图标"。
